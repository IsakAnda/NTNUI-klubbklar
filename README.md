# NTNUI-klubbklar
kode for å generere bestilling og faktura fra resultatene fra en google forms.

## Hvordan generere filer:
Skriv inn navn på excel filen du får fra formsen i ´main.py´ i variablene ´answer_filename´. Anngi navn/filplassering av faktura og bestillings excel filen. Og skriv inn start og sluttdato for nest bestilling. Kjør så ´main.py´ de to excel filene bør bli generet/oppdatert med alt du trenger.
